# 🌤️ Atmosphere — Modern Weather Dashboard

A sleek, responsive, and real-time weather application built with Vanilla JavaScript, HTML5, and CSS3. Powered by the authenticated **OpenWeatherMap API**, Atmosphere delivers instant weather updates, 5-day forecasts, dynamic UI updates, and location-based weather detection.

---

## ✨ Features

- **Real-Time Weather Metrics:** Live updates for Temperature, Humidity, Wind Speed, Feels Like, and UV Index.
- **5-Day Weather Forecast:** Instant multi-day weather predictions with high/low temperature breakdowns.
- **Global City Search:** Search weather condition data for any city worldwide.
- **Auto Geolocation:** Detect your current location with one click using the browser Geolocation API.
- **Dynamic Themes & Icons:** Visual elements and backgrounds adjust based on live weather conditions.
- **Responsive Design:** Optimized layout for desktop, tablet, and mobile screens.

---

## 🛠️ Built With

- **HTML5** — Semantic page structure and modern accessibility layout
- **CSS3** — Custom CSS variables, Flexbox, and CSS Grid
- **JavaScript (ES6+)** — Fetch API, Async/Await, DOM manipulation
- **OpenWeatherMap API** — Authenticated API integration for current weather and 5-day forecast data
